# App Privacy questionnaire (App Store Connect)

Answer: **Data Not Collected**. Ebb does not collect any data from this app.

Reasoning per Apple's definitions: data is "collected" when it is transmitted off the device. Ebb transmits nothing. HealthKit reads stay on the device. Optional model downloads on Android are outbound file requests with no user data.

Health & Fitness data: select "No" for collection. When asked whether the app uses HealthKit, answer yes and explain (see review-notes.md) that data is read on-device only.

Tracking: No. There is no advertising SDK and no identifier is used.

Google Play Data safety (for later): "No data collected", "No data shared", data encrypted in transit not applicable, users can request deletion in-app (Settings → Data). Health Connect permissions: read sleep and resting heart rate; declare in the Health apps declaration form.
